# Day84 — App (frontend)

Svelte 5 + Vite, wrapped by Capacitor for iOS/Android, also deployable as a standalone PWA.

See the root [`../README.md`](../README.md) for the full project overview, and [`../docs/architecture.md`](../docs/architecture.md) for how this frontend is structured.

## Commands

```bash
npm install
npm run dev      # local dev server
npm run build    # production build -> dist/
npx cap sync     # push the built web app into android/ and ios/
```
